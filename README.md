A program that writes one kind, funny fortune for a houseplant — 112 characters — to `/output/entry.txt`, for make.fun's "Fortune in a Pot" bounty. The fortune was picked from ten candidates scored against the judge's own brief: a prediction about the plant's own future, a small joke that lands, warm with no doom, and specific to the plant on the windowsill.

## Run it

```sh
python3 main.py
```
